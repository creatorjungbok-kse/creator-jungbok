실손24로 청구하다가 "서류를 보완해 주세요"라는 연락을 받으면 어디서 무엇을 올려야 할지 당황스럽죠.

결론부터 말하면 **실손24가 대신 보내 주는 서류는 네 가지뿐이고, 진단서 같은 서류는 직접 떼서 사진으로 올려야 해요.** 보완 요청을 받았다면 청구이력의 서류보완청구 버튼 하나만 기억하면 돼요.

## 실손24 서류 자동으로 가는 것과 직접 떼는 것

참여 병원·약국에서 2024년 10월 25일 이후에 받은 진료라면 아래 왼쪽 서류는 실손24가 보험사로 자동으로 보내요.

| 자동으로 보내는 서류 | 직접 떼서 첨부하는 서류 |
|---|---|
| 진료비 영수증(계산서) | 진단서 |
| 진료비 세부내역서 | 수술확인서 |
| 처방전 | 입퇴원확인서 |
| 약제비 영수증 | 그 밖에 보험사가 요구하는 서류 |

보험사가 다른 서류를 요구하지 않는 청구라면 서류를 따로 뗄 필요가 없어요. 입원이나 수술처럼 진단서가 필요한 청구는 병원에서 미리 떼 두세요.

금액별로 어떤 서류가 필요한지는 [실손보험 청구 서류 정리](/money/silson-insurance-claim/)에서 확인할 수 있어요.

## 실손24 서류 첨부 방법

실손24 청구 과정 중간에 **추가서류 제출** 단계가 있어요. 여기서 진단서나 확인서를 사진 찍거나 스캔해서 올리면 돼요.

| 상황 | 첨부할 서류 |
|---|---|
| 입원·수술 청구 | 진단서, 입퇴원확인서, 수술확인서 |
| 병원은 참여, 약국은 미참여 | 약국에서 받은 약제비 영수증 |
| 병원은 미참여, 약국은 참여 | 병원에서 뗀 진료비 영수증, 세부내역서, 처방전 |

병원이 참여하지 않고 약국만 참여했다면, 병원 선택 화면 오른쪽 위의 **약국만 청구**를 눌러 약국을 고르고 병원 서류는 추가서류로 첨부해요. 병원과 약국이 모두 참여하지 않았다면 실손24로는 청구할 수 없고 보험사에 직접 청구해야 해요.

## 실손24 서류 보완하는 법

청구를 마친 뒤 보험사가 서류를 더 내라고 하거나, 서류를 빠뜨린 걸 알았다면 이 순서대로 하면 돼요.

1. 실손24 앱이나 홈페이지에 **로그인**해요.
2. **마이페이지 → 청구이력**으로 들어가요.
3. 보완할 청구건의 **서류보완청구** 버튼을 눌러요.
4. 요청받은 서류를 **사진이나 스캔으로 첨부**해요.
5. 서류를 올리고 **제출까지** 마치면 추가 서류가 보험사로 넘어가요.

서류보완청구 버튼이 보이지 않는 청구건이라면 가입한 보험사에 직접 문의해서 보험사가 알려 주는 방법으로 내면 돼요. 어떤 서류를 더 내야 하는지도 보험사에 먼저 확인하고 떼는 게 헛걸음을 줄여요.

## 실손24 서류 확인과 다운방법

실손24가 보험사로 보낸 서류는 실손24 안에서 확인할 수 있어요. 다만 다운로드는 서류마다 달라요.

| 구분 | 확인하는 곳 | 다운로드 |
|---|---|---|
| 아직 청구하지 않은 진료 | 나의 실손청구 → 보험사 조회 → 병원 조회 → 병원 선택 → 진료내역의 미청구 항목 오른쪽 위 점 3개 | 미리보기만 가능(다운로드·스캔 불가) |
| 청구를 마친 진료 | 마이페이지 → 청구이력 → 제출서류 | 자동 전송 서류는 불가 |
| 내가 첨부한 추가서류 | 마이페이지 → 청구이력 → 제출서류 | 가능 |

미리보기는 본인 청구건에서만 돼요. 자녀청구나 부모님 대신 청구한 건은 볼 수 없어요.

자동 전송 서류는 다운로드가 안 되니, 종이로 꼭 필요하다면 병원에서 따로 발급받아야 해요. 실손24의 영수증은 병원 영수증과 모양이 달라 보일 수 있는데, 표준 서식을 써서 그렇고 내용은 같아요.

## 실손24 진단서 제출

진단서는 실손24가 자동으로 보내지 않아요. 병원에서 직접 발급받아 사진으로 올려야 해요.

| 확인할 것 | 내용 |
|---|---|
| 어디서 떼나요 | 진료받은 병원 원무과 |
| 발급비 | 병원마다 다르고, 보건복지부 기준 일반진단서는 2만원까지 |
| 더 싼 대안 | 입원 50만원 이하는 진단명이 적힌 입퇴원확인서(3천원까지)로 대신할 수 있어요 |
| 올리는 곳 | 청구할 때 추가서류 단계, 또는 청구 뒤 서류보완청구 |

진단서에는 진단명(질병분류기호)이 꼭 적혀 있어야 해요.

## 실손24 보험청구 실패했을 때

'청구 실패' 알림톡을 받았다면 실손24 담당자가 1일에서 2일 정도 원인을 확인하고 전화로 알려 줘요.

| 안내받은 내용 | 할 일 |
|---|---|
| 원인을 고쳤어요 | 실패한 때부터 3일(72시간) 안에 실손24 앱에서 다시 전송 |
| 고치는 데 오래 걸려요 | 실패한 때부터 72시간이 지나면 청구를 삭제할 수 있고, 삭제 뒤 보험사에 직접 청구하거나 고쳐진 뒤 다시 청구 |

부모님·제3자 청구건은 삭제 후 다시 청구할 때 위임 동의를 다시 받아야 해요.

청구 중에 "현재 병원 사정으로 인해 청구가 어려워요"라는 문구가 나오면 병원이나 약국이 문을 닫았거나 잠시 연결이 끊긴 거예요. 잠시 뒤 다시 해 보고, 계속 안 되면 환자등록번호, 병원명, 진료과와 진료일, 진료일별 수납금액을 확인해 고객센터에 문의하세요.

## 실손24 청구 취소하는 법

청구를 마친 뒤 서류를 잘못 보냈거나, 질병·상해를 잘못 골랐거나, 계좌나 보험사를 잘못 선택했다면 취소하고 다시 청구할 수 있어요.

1. **실손24 고객센터에** 전화(1811-3000)해 취소를 요청해요. 본인 확인 뒤 취소해 줘요.
2. 이미 보험사로 넘어가 심사가 시작됐을 수 있어요. **가입한 보험사에도 꼭 연락**해서 취소해요.
3. 취소된 진료내역은 실손24에서 **다시 청구**할 수 있어요.

고객센터는 평일 오전 9시부터 오후 6시, 토요일 오전 9시부터 오후 1시까지 운영해요(일요일·공휴일 제외).

진료내역이 보이는데 선택이 안 된다면 보험계약 조회 화면에서 넣은 '최초진료일자(사고발생일자)'를 확인하세요. 그 날짜보다 앞선 진료는 고를 수 없어요.

정리하면 **영수증·세부내역서·처방전·약제비 영수증은 자동, 진단서는 직접 첨부, 보완은 청구이력의 서류보완청구**예요. 청구 순서가 처음이라면 [실손24 보험청구 방법](/money/silson24-claim/)부터 보세요.
