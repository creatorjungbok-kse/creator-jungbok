사업자등록번호를 알고 있다면 홈택스에서 현재 사업 상태를 확인할 수 있습니다. 상호명만으로 사업자등록번호를 찾아주는 기능은 아닙니다.

## 무엇을 확인하려는지부터 고르세요

<div class="table-cards">

| 확인하려는 것 | 방법 |
|---|---|
| 거래처가 지금 영업 중인지, 휴·폐업했는지 | 홈택스 사업자상태 조회(로그인 없이 1건씩) |
| 세금계산서를 받을 수 있는 상대인지 | 같은 조회로 과세유형 확인 → 간이과세자면 세금계산서 발급 사업자인지 거래처에 확인 |
| 받은 번호·대표자명·개업일자가 실제 등록정보와 맞는지 | 국세청 공공데이터 진위확인 API(시스템 연동, 주로 기업용) 또는 거래처에 사업자등록증명 요청 |
| 상호명만 알고 번호를 찾고 싶음 | 조회로는 불가 → 거래처에 직접 받거나 세금계산서·영수증의 번호 확인 |
| 거래처 수십·수백 곳을 한꺼번에 점검 | 공공데이터포털 상태조회 API(1회 최대 100건) |
| 내 사업자등록 정보를 서류로 내야 함 | 조회 결과가 아니라 사업자등록증·사업자등록증명 발급 |

</div>

서류 발급 방법은 [사업자등록증·사업자등록증명 발급](/business/business-registration-certificate/)에 정리했습니다.

## 어디서 조회하나

1. 홈택스(hometax.go.kr)에 들어갑니다. 로그인하지 않아도 됩니다.
2. **증명·등록·신청·사업장현황 → 사업자등록 신청·정정·휴폐업 → 사업자상태 조회(사업자등록번호)** 로 들어갑니다. **상담·불복·제보 → 기타 → 사업자상태** 메뉴로도 같은 화면에 갈 수 있습니다.
3. 사업자등록번호 10자리를 넣고 **조회**를 누릅니다.

2026년 10월 15일 확인한 메뉴 경로입니다. 메뉴가 바뀌면 홈택스 검색창에서 '사업자상태'를 검색하세요.

## 결과가 이렇게 나오면

결과 표에는 사업자등록번호, 사업자등록상태, 조회기준일자가 나옵니다.

<div class="table-cards">

| 결과 | 뜻 | 거래 전에 할 일 |
|---|---|---|
| 부가가치세 일반과세자입니다. | 계속 사업 중인 일반과세자 | 과세 거래라면 세금계산서 발급 여부를 거래처에 확인 |
| 간이과세자로 나옴 | 계속 사업 중인 간이과세자 | 세금계산서가 필요하면 발급하는 사업자인지 거래처에 확인 |
| 면세사업자로 나옴 | 부가세가 면제되는 사업자 | 해당 거래가 면세 거래인지 확인하고, 계산서·영수증 등 필요한 증빙을 거래처에 확인 |
| 휴업자로 나옴 | 사업을 잠시 쉬는 상태 | 대금 지급·계약 전에 거래처에 재개 여부 확인 |
| 폐업자 (과세유형, 폐업일자 표시) | 폐업한 사업자 | 폐업일자를 확인하고, 거래처가 새 사업자번호로 영업 중인지 확인 |
| 사업자단위과세로 전환된 폐업자 | 본사 번호 하나로 묶이면서 예전 번호가 폐업 처리됨 | 실제로 문을 닫은 것은 아닐 수 있으니 거래처에 바뀐 번호 확인 |
| 국세청에 등록되지 않은 사업자등록번호입니다. | 국세청에 없는 번호 | 번호를 다시 확인. 최근 개업했다면 사업자등록 처리 여부도 거래처에 확인 |

</div>

표의 '거래 전에 할 일'은 조회 결과에 따른 확인 사항입니다. 실제 거래와 증빙 발급 가능 여부는 거래처에 별도로 확인하세요.

간이과세자 중 세금계산서를 발급하는 경우와 영수증만 발급하는 경우의 차이는 [간이과세자 vs 일반과세자](/business/simplified-taxpayer/)에서 확인하세요.

## 이 조회로는 알 수 없는 것

- **상호, 대표자명, 주소**는 나오지 않습니다.
- **상호명으로 사업자등록번호를 찾을 수 없습니다.** 번호는 거래처에서 직접 받아야 합니다.
- **법적 증빙이 아닙니다.** 홈택스 조회 결과는 사업자 간 거래에서 피해를 막기 위한 최소한의 정보라서, 증빙자료로서 법적 효력은 없습니다.
- **처리 전 변경은 반영되지 않습니다.** 세무서가 신규등록·휴업·폐업 처리를 마친 뒤에만 반영됩니다.

## 기업이 여러 곳을 확인한다면

공공데이터포털의 국세청 사업자등록정보 진위확인 및 상태조회 서비스(오픈 API)를 쓸 수 있습니다.

- **상태조회**: 사업자등록번호만으로 계속·휴업·폐업 상태, 과세유형, 폐업일자를 조회합니다. 1회 최대 100건, 하루 100만 건까지입니다.
- **진위확인**: 사업자등록번호·개업일자·대표자명 등을 넣어 국세청 등록정보와 일치하는지 확인합니다. 대표자명을 보여주지는 않고 일치 여부만 알려줍니다.
- 국세청 등록정보와 30분 주기로 맞춰지며, 신규 개업자는 반영까지 1~2일이 걸립니다.
