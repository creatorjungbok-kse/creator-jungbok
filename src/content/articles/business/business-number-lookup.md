사업자등록번호만 알면 홈택스에서 그 사업자가 지금 영업 중인지 바로 조회할 수 있어요. 조회 방법과 결과 보는 법, 조회가 안 될 때 확인할 것을 순서대로 정리했어요.

다만 상호명으로 번호를 찾아 주는 기능은 아니에요. 상호나 주소를 알고 싶다면 아래에서 다른 방법을 알려 드릴게요.

## 사업자번호 조회로 확인할 수 있는 것

목적에 따라 확인하는 곳이 달라요.

<div class="table-cards">

| 확인하려는 것 | 방법 |
|---|---|
| 거래처가 지금 영업 중인지, 휴·폐업했는지 | 홈택스 사업자상태 조회(로그인 없이 1건씩) |
| 세금계산서를 받을 수 있는 상대인지 | 같은 조회로 과세유형 확인 → 간이과세자면 세금계산서 발급 사업자인지 거래처에 확인 |
| 받은 번호·대표자명·개업일자가 실제 등록정보와 맞는지 | 국세청 공공데이터 진위확인 API(시스템 연동, 주로 기업용) 또는 거래처에 사업자등록증명 요청 |
| 상호명만 알고 번호를 찾고 싶음 | 조회로는 불가 → 거래처에 직접 받거나 세금계산서·영수증의 번호 확인 |
| 거래처 수십·수백 곳을 한꺼번에 점검 | 공공데이터포털 상태조회 API(1회 최대 100건) |
| 내 사업자등록 정보를 서류로 내야 함 | 조회 결과가 아니라 사업자등록증·사업자등록증명 발급 |

</div>

서류 발급 방법은 [사업자등록증·사업자등록증명 발급](/business/business-registration-certificate/)에 정리해 뒀어요.

## 사업자번호 조회 방법

  <figcaption>국세청 홈택스 ‘사업자등록상태조회’ 화면이에요. 로그인 없이 쓸 수 있어요. (2026년 11월 1일 확인)</figcaption>

1. 홈택스(hometax.go.kr)에 들어가요. 로그인은 하지 않아도 돼요.
2. 사업자상태 조회 메뉴로 가요. 검색창에 '사업자상태'를 넣어도 돼요.
3. 조회할 사업자등록번호 10자리를 넣어요.
4. **조회**를 누르면 계속·휴업·폐업 상태와 과세유형이 나와요.

메뉴 경로는 **증명·등록·신청·사업장현황 → 사업자등록 신청·정정·휴폐업 → 사업자상태 조회(사업자등록번호)** 순서예요. **상담·불복·제보 → 기타 → 사업자상태**로 들어가도 같은 화면이 나와요.

2026년 11월 1일에 확인한 경로예요. 메뉴가 바뀌었다면 홈택스 검색창에 '사업자상태'를 입력해 보세요.

## 사업자번호 조회 결과 보는 법

결과 표에는 사업자등록번호, 사업자등록상태, 조회기준일자가 나와요. 상태별로 보면 이래요.

<div class="table-cards">

| 결과 | 뜻 | 거래 전에 할 일 |
|---|---|---|
| 부가가치세 일반과세자입니다. | 계속 사업 중인 일반과세자 | 과세 거래라면 세금계산서 발급 여부를 거래처에 확인 |
| 간이과세자로 나옴 | 계속 사업 중인 간이과세자 | 세금계산서가 필요하면 발급하는 사업자인지 거래처에 확인 |
| 면세사업자로 나옴 | 부가세가 면제되는 사업자 | 해당 거래가 면세 거래인지 확인하고, 계산서·영수증 등 필요한 증빙을 거래처에 확인 |
| 휴업자로 나옴 | 사업을 잠시 쉬는 상태 | 대금 지급·계약 전에 거래처에 재개 여부 확인 |
| 폐업자 (과세유형, 폐업일자 표시) | 폐업한 사업자 | 폐업일자를 확인하고, 거래처가 새 사업자번호로 영업 중인지 확인 |
| 사업자단위과세로 전환된 폐업자 | 본사 번호 하나로 묶이면서 예전 번호가 폐업 처리됨 | 실제로 문을 닫은 것은 아닐 수 있으니 거래처에 바뀐 번호 확인 |
| 국세청에 등록되지 않은 사업자등록번호입니다. | 국세청에 없는 번호 | 번호를 다시 확인. 최근 개업했다면 사업자등록 처리 여부도 거래처에 확인 |

</div>

'거래 전에 할 일'은 조회 결과에 따라 확인할 점이에요. 실제 거래와 증빙 발급이 되는지는 거래처에 따로 확인하세요.

간이과세자 중 세금계산서를 발급하는 경우와 영수증만 발급하는 경우의 차이는 [간이과세자 vs 일반과세자](/business/simplified-taxpayer/)에서 볼 수 있어요.

## 사업자번호 조회 안됨

조회가 안 되거나 결과가 이상하면 아래를 차례로 확인하세요.

| 이럴 때 | 확인할 것 |
|---|---|
| '국세청에 등록되지 않은 사업자등록번호입니다'가 나옴 | 숫자 10자리를 빠짐없이 넣었는지, 거래처가 알려 준 번호가 맞는지 다시 확인해요. 최근 개업했다면 세무서 등록 처리가 끝났는지 거래처에 물어봐요 |
| 조회를 눌러도 결과가 비어 있음 | 번호 형식이 맞지 않으면 결과가 나오지 않을 수 있어요. 번호를 다시 넣고 조회해요 |
| 폐업했다는 거래처가 '계속'으로 나옴 | 세무서가 폐업 처리를 마친 뒤에만 반영돼요. 거래처에 폐업 처리 여부를 직접 확인해요 |
| 상호로 검색했는데 아무것도 안 나옴 | 이 조회는 번호로만 돼요. 상호로 찾는 방법은 아래 '사업자번호로 상호 주소 확인하는 법'을 보세요 |
| 메뉴를 못 찾겠음 | 홈택스 검색창에 '사업자상태'를 넣으면 같은 화면으로 가요 |

## 내 사업자번호를 조회할 때

저도 사업자번호 조회는 많이 해 봤는데요. 번호만 입력하고 조회를 누르면 바로 결과가 나와서 편리하더라고요.

상황별로 이렇게 보이니 참고하세요.

| 상황 | 이렇게 보여요 |
|---|---|
| 폐업한 뒤 | 세무서가 폐업 처리를 마치면 폐업자와 폐업일자가 나와요. 처리 전이면 아직 이전 상태로 보일 수 있어요 |
| 새로 사업자를 낸 뒤 | 세무서 등록 처리가 끝나야 조회돼요. 공공데이터 API는 하루이틀 더 걸릴 수 있어요 |
| 내 번호 자체를 모를 때 | 이 조회로는 번호를 알 수 없어요. 홈택스에 로그인해 사업자등록증 재발급이나 사업자등록증명 발급 화면에서 확인해요. 폐업했다면 폐업사실증명에 나와요 |

## 사업자등록번호 뜻

사업자등록번호는 사업자등록을 하면 세무서가 부여하는 10자리 번호예요. 보통 000-00-00000 형태로 써요.

세금계산서·영수증·카드 매출전표에 적히고, 거래처가 정상 사업자인지 확인할 때 쓰여요.

가운데 두 자리는 개인과 법인 같은 사업자 구분에, 마지막 자리는 번호가 맞게 입력됐는지 검증하는 데 쓰여요. 그렇다고 번호만 보고 업종이나 지역을 단정하지는 마세요.

비즈노, 더비즈 같은 민간 사이트에서는 상호로 검색하거나 상호·주소·전화번호를 함께 볼 수 있어요. 홈택스에는 안 나오는 정보라 많이들 찾죠.

하지만 이런 점은 알고 쓰세요.

- 공공기관 자료를 모아 **다시 가공한 정보**예요. 비즈노도 갱신 시점에 따라 현재 정보와 다를 수 있고 참고용이라고 안내해요.
- 주소·전화번호가 비어 있거나 예전 정보일 때가 있어요.
- 휴업·폐업 상태는 거래 직전에 **홈택스에서 다시 확인**하는 게 안전해요.

## 사업자번호로 상호 주소 확인하는 법

<div class="table-cards">

| 상황 | 확인하는 곳 | 알 수 있는 것 |
|---|---|---|
| 온라인 쇼핑몰·판매자 | 공정거래위원회 사업자정보공개 → 통신판매사업자 | 사업자등록번호·회사명·대표자로 검색해 상호, 대표자, 운영상태, 신고일자 등 확인 |
| 법인 거래처 | 대법원 인터넷등기소 법인 등기사항증명서 | 상호, 본점 주소, 대표이사·임원 등. 누구나 수수료를 내고 열람·발급 가능. 사업자등록번호가 아니라 상호나 법인등록번호로 검색 |
| 그 밖의 개인사업자 | 거래처에 사업자등록증 사본 요청 | 상호, 대표자, 사업장 주소, 업태·종목 |

</div>

공정위 조회에는 통신판매업 신고를 한 사업자만 나오고, 지자체 변경사항은 하루이틀 뒤에 반영돼요. 공정위도 세법상 폐업 여부는 홈택스에서 따로 확인하라고 안내해요.

## 이 조회로는 알 수 없는 것

| 알 수 없는 것 | 이유 |
|---|---|
| 상호, 대표자명, 주소 | 홈택스 조회 결과에 나오지 않아요 |
| 상호명으로 번호 찾기 | 번호를 넣어 상태를 보는 기능이라 번호는 거래처에서 받아야 해요 |
| 법적 증빙 | 거래 피해를 막기 위한 최소한의 정보라 증빙으로서 법적 효력은 없어요 |
| 처리 전 변경 | 세무서가 신규등록·휴업·폐업 처리를 마친 뒤에만 반영돼요 |

## 기업이 여러 곳을 확인한다면

공공데이터포털의 국세청 사업자등록정보 진위확인 및 상태조회 서비스(오픈 API)를 쓰면 돼요.

| 기능 | 내용 |
|---|---|
| 상태조회 | 사업자등록번호만으로 계속·휴업·폐업 상태, 과세유형, 폐업일자 조회. 1회 최대 100건, 하루 100만 건까지 |
| 진위확인 | 사업자등록번호·개업일자·대표자명 등을 넣어 등록정보와 일치하는지 확인. 대표자명을 보여 주지는 않고 일치 여부만 알려 줘요 |

국세청 등록정보와 30분 주기로 맞춰지고, 신규 개업자는 반영까지 하루이틀이 걸려요.
