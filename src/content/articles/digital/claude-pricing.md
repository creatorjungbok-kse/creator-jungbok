저는 1년 넘게 꾸준히 클로드를 써 왔어요. 처음에는 20달러짜리(Pro)를 쓰다가, 클로드 코드가 나온 뒤로는 200달러짜리(Max 20x)로 올렸어요.

그런데 중간에 토큰(사용량)이 너무 남더라고요... 그래서 100달러짜리(Max 5x)로 바꿨고, 지금도 100달러짜리를 쓰고 있어요. 이 경험을 바탕으로 가격, 차이, 추천까지 핵심만 정리해 볼게요.

가격과 기능은 2026년 10월 28일 Anthropic 공식 요금 페이지 기준이에요. 이후에 바뀌기도 해요.

## 클로드 요금제 가격

<figure class="shot">
  <a href="/images/articles/claude-pricing-card-1.webp" class="shot__zoom"><img src="/images/articles/claude-pricing-card-1.webp" width="800" height="419" alt="클로드 개인 요금제 세전 공식 가격. Pro는 월 20달러로 한국 표시 가격은 월 22달러, Max 5x는 월 100달러로 한국 표시 가격은 110달러부터, Max 20x는 월 200달러로 한국 표시 가격은 약 220달러. 2026년 10월 28일 Anthropic 공식 요금 페이지 기준." loading="lazy" decoding="async"></a>
  <figcaption>한국에서는 부가세 10%가 붙은 가격으로 보여요.</figcaption>
</figure>

공식 가격은 달러 기준이고 세금이 따로예요. 한국에서 요금 페이지에 들어가면 부가세 10%가 붙은 가격으로 보여요.

Free는 $0이에요. Pro는 월 $20인데 연간 구독하면 월 $17(선불 $200)이고, 한국 표시 가격으로는 월 $22, 연간이면 월 $18(선불 $220)이에요.

Max 5x는 월 $100(한국 표시 $110부터), Max 20x는 월 $200이에요. Max 20x 한국 표시 가격은 세전 $200에 부가세 10%를 더한 약 $220이고요.

Max는 월간 결제만 있어요. 연간 할인은 Pro와 Team에만 있고, 원화로 얼마가 빠져나가는지는 카드사 환율과 해외 결제 수수료에 따라 달라지니 카드 명세서로 확인하세요.

### 클로드 요금제 팀

회사나 팀에서 같이 쓴다면 Team 플랜이 있어요. 2명부터 150명까지 쓸 수 있고, 시트 종류를 섞어서 고르면 돼요.

| 시트 | 공식 가격(세전) | 한국 표시 가격(부가세 포함) |
|---|---|---|
| 스탠다드 | 연간 청구 시 시트당 월 $20, 월간 $25 | 연간 $22, 월간 $27.50 |
| 프리미엄(스탠다드의 5배 사용량) | 연간 청구 시 시트당 월 $100, 월간 $125 | 연간 $110, 월간 $137.50 |

Team에는 중앙 청구, 싱글 사인온(SSO), 관리자 제어 같은 기능이 붙고, 기본적으로 사용자 콘텐츠로 모델을 학습하지 않아요. 더 큰 회사용 Enterprise는 시트당 월 US$20에 API 요금 기준 사용량이 더해지고, 연간 청구에 최소 20시트예요.

## 클로드 요금제 차이

가장 크게 갈리는 건 쓸 수 있는 양(사용량)이에요. 기능은 Pro부터 거의 다 열려요.

<div class="table-cards">

| 구분 | Free | Pro | Max |
|---|---|---|---|
| 사용량 | 기본 | Free보다 5시간 세션당 최소 5배 | Pro의 5배 또는 20배 |
| Claude Code | 없음 | 포함 | 포함 |
| Opus 모델·리서치 | 없음 | 포함 | 포함 |
| 프로젝트 | 최대 5개 | 무제한 | 무제한 |

</div>

Max는 여기에 더 높은 출력 한도, 새 기능 먼저 쓰기, 트래픽이 몰릴 때 우선 접근이 붙어요. 무료 플랜에서도 채팅, 웹 검색, 파일 생성, 메모리, 커넥터는 다 돼요.

Max에는 월간 API 크레딧도 있어요. Max 5x는 월 $100, Max 20x는 월 $200 상당의 Claude Platform 크레딧을 받는데, 별도 연결과 자격 조건이 있고 Claude 채팅·Claude Code 사용량에는 안 쓰여요.

### 클로드 요금제 토큰과 사용량 한도

<figure class="shot">
  <a href="/images/articles/claude-pricing-card-2.webp" class="shot__zoom"><img src="/images/articles/claude-pricing-card-2.webp" width="800" height="570" alt="클로드 사용량 한도 기준. 모든 플랜에 5시간 세션 한도가 있고 5시간마다 다시 채워진다. 유료 플랜에는 주간 한도도 있다. 웹, 데스크톱, 모바일, Claude Code 사용량이 같은 한도에서 빠진다. 대화 길이, 첨부 파일, 고른 모델, 쓰는 기능에 따라 쓸 수 있는 양이 달라진다." loading="lazy" decoding="async"></a>
  <figcaption>지금 얼마나 썼는지는 설정 > 사용량에서 봐요.</figcaption>
</figure>

'토큰'으로 많이 검색하시는데, 구독 요금제는 토큰 몇 개처럼 정해진 양이 없어요. 모든 플랜에 **5시간 세션 한도**가 있고, 5시간마다 다시 채워져요.

유료 플랜에는 일주일 단위 **주간 한도**도 있어요. 웹, 데스크톱, 모바일, Claude Code 사용량이 모두 한 통에서 같이 빠지고, 대화 길이나 첨부 파일, 고른 모델, 쓰는 기능에 따라 쓸 수 있는 양이 달라져요.

지금 얼마나 썼는지는 설정 > 사용량에서 언제든 보면 돼요. 한도를 다 쓰면 초기화를 기다리거나 상위 플랜으로 올리면 되고, 사용 크레딧을 켜서 표준 API 요금으로 계속 쓰는 방법도 있어요.

## 클로드 요금제 추천

<figure class="shot">
  <a href="/images/articles/claude-pricing-card-3.webp" class="shot__zoom"><img src="/images/articles/claude-pricing-card-3.webp" width="800" height="528" alt="1년 넘게 써 본 경험으로 정리한 클로드 요금제 추천. 가끔 질문하고 글을 다듬는 정도면 Free 0달러, 일반적인 사용이면 Pro 월 20달러, 사업이나 코딩, Claude Code 작업이면 Max 5x 월 100달러, Max 5x 한도에 자주 걸릴 만큼 방대한 작업이면 Max 20x 월 200달러." loading="lazy" decoding="async"></a>
  <figcaption>제가 직접 써 보고 정리한 기준이에요.</figcaption>
</figure>

그냥 쓰시는 분들은 무료로도 가능해요. 하지만 일단 20달러짜리(Pro)로도 충분하다고 생각해요.

사업이나 코딩 작업, 클로드 코드처럼 일에 본격적으로 쓰려면 이야기가 달라져요. 20달러짜리는 부족했고, 100달러짜리가 적당했어요.

200달러짜리도 써 봤지만, 웬만큼 방대한 양의 작업이 아니라면 100달러짜리를 먼저 써 보는 걸 추천해요. 저처럼 토큰(사용량)이 남아도는 경우가 생기거든요!

클로드 코드를 쓰실 거라면 [클로드 코드 요금제](/digital/claude-code-pricing/) 글에서 사용량과 로그인 주의점도 같이 확인해 보세요.

## 클로드 요금제 변경 방법

웹이나 데스크톱에서 결제했다면 설정 > 청구 > 구독 관리에서 바꿔요. 바꾸는 방향에 따라 적용 시점이 달라요.

| 바꾸는 방향 | 적용 시점 |
|---|---|
| 업그레이드(예: Pro에서 Max) | 즉시 적용, 남은 기간은 새 플랜에 크레딧으로 반영 |
| 다운그레이드(예: Max 20x에서 5x) | 현재 결제 주기가 끝날 때 적용 |
| 월간에서 연간으로(Pro) | 남은 기간은 첫 연간 청구서에 크레딧으로 반영 |

다운그레이드해도 채팅, 프로젝트, 파일은 계정에 그대로 남아요. Team 플랜은 소유자가 조직 설정 > 청구에서 관리해요.

### 해지할 때

구독은 언제든 취소할 수 있고, 현재 결제 주기가 끝날 때까지는 계속 써요. 다음 결제를 막으려면 **갱신일 최소 24시간 전에** 취소하세요.

App Store나 Google Play로 구독했다면 그 앱스토어의 구독 관리에서 취소해야 해요. 결제는 일반적으로 환불되지 않는다고 안내돼 있어요.
