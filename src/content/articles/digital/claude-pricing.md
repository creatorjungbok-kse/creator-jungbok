저는 1년 넘게 꾸준히 클로드를 써 왔어요. 처음에는 20달러짜리(Pro)를 쓰다가, 클로드 코드가 나온 뒤로는 200달러짜리(Max 20x)로 올렸어요.

그런데 중간에 토큰(사용량)이 너무 남더라고요... 그래서 100달러짜리(Max 5x)로 바꿨고, 지금도 100달러짜리를 쓰고 있어요. 이 경험을 바탕으로 가격, 차이, 추천까지 핵심만 정리해 볼게요.

가격과 기능은 2026년 10월 28일 Anthropic 공식 요금 페이지 기준이에요. 바뀔 수 있어요.

## 클로드 요금제 가격

공식 가격은 달러 기준이고 세금이 따로예요. 한국에서 요금 페이지에 들어가면 부가세 10%가 포함된 가격으로 보여요.

| 요금제 | 공식 가격(세전) | 한국 표시 가격(부가세 포함) |
|---|---|---|
| Free | $0 | $0 |
| Pro | 월 $20, 연간 구독 시 월 $17(선불 $200) | 월 $22, 연간 구독 시 월 $18(선불 $220) |
| Max 5x | 월 $100 | $110부터 |
| Max 20x | 월 $200 | 약 $220(세전 $200에 부가세 10%) |

Max는 월간 결제만 있고, 연간 할인은 Pro와 Team에만 있어요. 원화로 얼마가 빠져나가는지는 카드사 환율과 해외 결제 수수료에 따라 달라지니 카드 명세서로 확인하세요.

## 클로드 요금제 차이

가장 큰 차이는 쓸 수 있는 양(사용량)이에요. 기능은 Pro부터 거의 다 열려요.

<div class="table-cards">

| 구분 | Free | Pro | Max |
|---|---|---|---|
| 사용량 | 기본 | Free보다 5시간 세션당 최소 5배 | Pro의 5배 또는 20배 |
| Claude Code | 없음 | 포함 | 포함 |
| Opus 모델·리서치 | 없음 | 포함 | 포함 |
| 프로젝트 | 최대 5개 | 무제한 | 무제한 |

</div>

Max는 여기에 더 높은 출력 한도, 새 기능 먼저 쓰기, 트래픽이 몰릴 때 우선 접근이 붙어요. 무료 플랜에서도 채팅, 웹 검색, 파일 생성, 메모리, 커넥터는 쓸 수 있어요.

\* Max의 월간 API 크레딧: Max 5x는 월 $100, Max 20x는 월 $200 상당의 Claude Platform 크레딧을 받을 수 있어요. 별도 연결과 자격 조건이 있고, Claude 채팅·Claude Code 사용량에는 쓰이지 않아요.

## 클로드 요금제 토큰과 사용량 한도

'토큰'으로 많이 검색하시는데, 구독 요금제는 토큰 몇 개처럼 정해진 양이 없어요. 대신 이렇게 정해져요.

- **5시간 세션 한도**: 모든 플랜에 있고 5시간마다 다시 채워져요.
- **주간 한도**: 유료 플랜에는 일주일 단위 한도도 있어요.
- **한 통에서 같이 차감**: 웹, 데스크톱, 모바일, Claude Code 사용량이 모두 같은 한도에서 빠져요.
- **달라지는 기준**: 대화 길이, 첨부 파일, 고른 모델, 쓰는 기능에 따라 쓸 수 있는 양이 달라져요.

지금 얼마나 썼는지는 설정 > 사용량에서 언제든 볼 수 있어요. 한도를 다 쓰면 초기화를 기다리거나, 상위 플랜으로 올리거나, 사용 크레딧을 켜서 표준 API 요금으로 계속 쓸 수 있어요.

200달러짜리도 써 봤지만, 웬만큼 방대한 양의 작업이 아니라면 100달러짜리를 먼저 써 보는 걸 추천해요. 저처럼 토큰(사용량)이 남아도는 경우가 생기거든요!

## 클로드 요금제 팀

회사나 팀에서 같이 쓴다면 Team 플랜이 있어요. 2명부터 150명까지 쓸 수 있고, 시트 종류를 섞어서 고를 수 있어요.

| 시트 | 공식 가격(세전) | 한국 표시 가격(부가세 포함) |
|---|---|---|
| 스탠다드 | 연간 청구 시 시트당 월 $20, 월간 $25 | 연간 $22, 월간 $27.50 |
| 프리미엄(스탠다드의 5배 사용량) | 연간 청구 시 시트당 월 $100, 월간 $125 | 연간 $110, 월간 $137.50 |

Team은 중앙 청구, 싱글 사인온(SSO), 관리자 제어 같은 기능이 붙고, 기본적으로 사용자 콘텐츠로 모델을 학습하지 않아요. 더 큰 회사용 Enterprise는 시트당 월 US$20에 API 요금 기준 사용량이 더해지고, 연간 청구에 최소 20시트예요.

## 클로드 요금제 변경 방법

  <figcaption>설정 > 청구 > 구독 관리에서 바꿔요.</figcaption>

| 바꾸는 방향 | 적용 시점 |
|---|---|
| 업그레이드(예: Pro에서 Max) | 즉시 적용, 남은 기간은 새 플랜에 크레딧으로 반영 |
| 다운그레이드(예: Max 20x에서 5x) | 현재 결제 주기가 끝날 때 적용 |
| 월간에서 연간으로(Pro) | 남은 기간은 첫 연간 청구서에 크레딧으로 반영 |

다운그레이드해도 채팅, 프로젝트, 파일은 계정에 그대로 남아요. Team 플랜은 소유자가 조직 설정 > 청구에서 관리해요.

### 해지할 때

구독은 언제든 취소할 수 있고, 현재 결제 주기가 끝날 때까지는 계속 쓸 수 있어요. 다음 결제를 막으려면 갱신일 최소 24시간 전에 취소하세요.

App Store나 Google Play로 구독했다면 해당 앱스토어의 구독 관리에서 취소해야 해요. 결제는 일반적으로 환불되지 않는다고 안내돼 있어요.

## 결제 전에 확인할 것

- **API는 따로예요**: 유료 구독은 채팅 이용 상품이라 Claude API·Console은 포함되지 않아요. 개발용 API는 따로 설정하고 결제해요.
- **Claude Code에 API 키를 설정해 두었다면**: 구독 대신 API 요금이 청구될 수 있어요. ANTHROPIC_API_KEY 환경 변수가 있는지 확인하세요.
- **앱에서 결제하면**: Apple App Store나 Google Play가 결제를 처리하고, 결제 수단과 영수증도 앱스토어 계정에서 관리해요. 모바일 가격은 앱 플랫폼에 따라 다를 수 있어요.
- **웹 결제**: 신용카드나 체크카드로 해요. 저는 Visa 카드로 매달 자동 결제하고 있어요.
