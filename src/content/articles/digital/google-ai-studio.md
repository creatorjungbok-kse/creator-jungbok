제미나이를 더 깊게 써 보고 싶은데, 구글 AI 스튜디오는 화면부터 개발자용처럼 보여서 들어가자마자 막막하죠. 무료인지, 돈이 나가는 건 아닌지도 걱정되고요.

저는 유튜브 영상을 만들어 보려고 구글 AI 스튜디오를 써 본 적이 있어요. 이 글에서는 처음 시작하는 순서부터 한국어로 쓰는 법, 무료 크레딧에서 헷갈리는 부분, 요금제와 결제까지 정리했어요.

## 구글 AI 스튜디오 사용법

<figure class="shot">
  <a href="/images/articles/google-ai-studio-card-1.webp" class="shot__zoom"><img src="/images/articles/google-ai-studio-card-1.webp" width="800" height="774" alt="구글 AI 스튜디오 시작하는 법. 1 aistudio.google.com에 구글 계정으로 로그인해요. 2 플레이그라운드에서 새 채팅이 열려요. 3 오른쪽 실행 설정에서 모델과 시스템 요청 사항을 정해요. 4 메시지를 쓰고 실행을 눌러요." loading="lazy" decoding="async"></a>
  <figcaption>따로 결제하지 않으면 무료로 쓸 수 있어요.</figcaption>

1. **aistudio.google.com**에 들어가 구글 계정으로 로그인해요
2. 기본으로 **플레이그라운드**가 열리고 새 채팅이 준비돼 있어요
3. 오른쪽 위 **실행 설정**을 열어 모델과 **시스템 요청 사항**을 정해요
4. 아래 입력창에 메시지를 쓰고 **실행**을 눌러요

마음에 드는 결과가 나오면 **코드 가져오기**로 코드를 받을 수도 있어요. 직접 앱을 만들고 싶다면 **빌드 모드**에서 말로 설명해 앱을 만들 수 있어요.

## 구글 AI 스튜디오 한국어 설정

<figure class="shot">
  <a href="/images/articles/google-ai-studio-card-2.webp" class="shot__zoom"><img src="/images/articles/google-ai-studio-card-2.webp" width="800" height="570" alt="구글 AI 스튜디오 한국어로 쓰는 법. 실행 설정의 시스템 요청 사항에 항상 한국어로 답하라고 적고, 질문도 한국어로 그대로 쓰고, 메뉴가 영어로 보이면 크롬 번역을 쓰고, 결과 언어가 섞이면 다시 요청하세요." loading="lazy" decoding="async"></a>

답을 늘 한국어로 받고 싶다면 **실행 설정**의 <mark>시스템 요청 사항</mark>에 "항상 한국어로 답해 줘"라고 적어 두세요. 이 칸은 대화 중에도 언제든 바꿀 수 있어요.

질문은 처음부터 한국어로 그대로 써도 잘 알아들어요. 메뉴가 영어로 보여서 불편하다면 크롬 브라우저의 **번역** 기능으로 화면을 한국어로 바꿔 보세요.

## 구글 AI 스튜디오 앱

구글은 2026년 5월 열린 개발자 행사에서 **AI 스튜디오 모바일 앱 사전 등록**을 시작했다고 발표했어요. 앱이 정식으로 나오기 전에는 폰 브라우저로 aistudio.google.com에 들어가 쓰면 돼요.

또 빌드 모드에서는 **안드로이드 앱을 직접 만들** 수도 있어요. 만든 앱 중 처음 2개까지는 카드 없이 무료로 구글 클라우드에 올릴 수 있어요.

구글 AI 스튜디오는 **유료 API 키를 연결하지 않으면 무료**예요. 대신 모델마다 무료로 쓸 수 있는 한도가 있고, 가장 좋은 일부 모델과 영상 모델 **비오**는 무료로 쓸 수 없어요.

많이 헷갈리는 게 **300달러 웰컴 크레딧**이에요. 이건 구글 클라우드 크레딧이라, 2026년 3월 2일 이후 만든 결제 계정이면 제미나이 API와 AI 스튜디오 요금에는 쓸 수 없어요.

## 구글 AI 스튜디오 요금제와 결제하는 방법

<figure class="shot">
  <a href="/images/articles/google-ai-studio-card-3.webp" class="shot__zoom"><img src="/images/articles/google-ai-studio-card-3.webp" width="800" height="528" alt="구글 AI 스튜디오 요금. 무료는 기본 할당량을 0원에 쓰고, 구글 AI 프로와 울트라를 구독하면 더 높은 할당량을 쓰고, 유료 API 키를 연결하면 쓴 만큼 결제하며 최소 5달러를 선결제해요." loading="lazy" decoding="async"></a>
  <figcaption>유료 API 키를 연결하지 않으면 요금이 나가지 않아요.</figcaption>
</figure>

더 많이 쓰는 방법은 두 가지예요.

- **구글 AI 요금제 구독:** 구글 AI 프로나 울트라를 구독하면 AI 스튜디오 웹 화면에서 더 높은 할당량과 좋은 모델을 써요. 왼쪽 메뉴의 **Upgrade** 버튼에서 바꿀 수 있어요
- **유료 API 키 연결:** 쓴 만큼 돈을 내는 방식이에요. 처음엔 최소 5달러를 선결제해요

결제 연결은 이렇게 해요.

1. AI 스튜디오의 API 키나 프로젝트 화면에서 **Set up billing**을 눌러요
2. 국가를 고르고 약관에 동의한 뒤 연락처와 결제 수단을 넣어요
3. 최소 5달러를 선결제하면 연결이 끝나요

<div class="box box--warn"><span class="box__title">주의</span>유료 API 키를 연결하면 그때부터 AI 스튜디오 사용도 요금이 나가요. 가볍게 쓸 거라면 무료 상태로 두는 게 안전해요.</div>
