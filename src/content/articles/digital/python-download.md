파이썬 배워 보려고 검색했는데 다운로드 버튼부터 종류가 너무 많아서 멈칫하셨죠? 32비트, 64비트, 설치 관리자까지 뭘 눌러야 할지 헷갈려요.

저는 처음 설치할 때 PATH 체크를 안 하고 넘어갔다가, 설치는 다 됐는데 실행이 안 돼서 한참 헤맸어요... 그래서 이 글에는 받는 법부터 그 PATH 문제를 푸는 법까지 순서대로 담았어요.

## 파이썬 다운로드 무료로 받는 곳

  <figcaption>python.org 다운로드 페이지 기준이에요.</figcaption>

파이썬은 오픈소스라 **돈을 낼 일이 전혀 없어요.** 받는 곳은 공식 사이트 **python.org** 한 군데만 기억하면 돼요.

2026년 11월 17일 기준 최신 버전은 <mark>3.15.2</mark>예요. 특별한 이유가 없다면 가장 최신 버전을 받으면 되고, 쓰려는 프로그램이 특정 버전을 요구할 때만 그 버전을 고르세요.

<div class="box box--warn"><span class="box__title">주의</span>파이썬 설치 파일을 돈 받고 파는 사이트나 이상한 다운로드 사이트는 피하세요. python.org에서 받는 게 제일 안전해요.</div>

## 파이썬 설치 방법 윈도우

<figure class="shot">
  <a href="/images/articles/python-download-card-2.webp" class="shot__zoom"><img src="/images/articles/python-download-card-2.webp" width="800" height="774" alt="파이썬 설치 방법 윈도우. 1 python.org에서 Python install manager 파일을 받아요. 2 파일을 실행해 Install을 눌러요. 3 터미널을 열어 python을 입력해요. 4 PATH에 추가하라는 안내가 뜨면 추가를 고르면 편해요." loading="lazy" decoding="async"></a>
  <figcaption>마이크로소프트 스토어에서 받아도 같은 프로그램이니 둘 중 하나만 설치하세요.</figcaption>
</figure>

윈도우는 이제 **Python install manager**(설치 관리자)로 설치하는 게 공식 추천이에요. 마이크로소프트 스토어에서 받아도 똑같은 프로그램이에요.

1. python.org 다운로드 페이지에서 **설치 관리자**를 받아요
2. 받은 파일을 더블클릭하고 **Install**을 눌러요
3. 터미널(명령 프롬프트나 PowerShell)을 열고 **python**을 입력해요
4. 처음 실행할 때 PATH에 폴더를 추가할지 물어보면, 추가를 고르는 게 편해요

설치가 끝나면 python, py 명령을 바로 쓸 수 있어요. 버전을 여러 개 깔아 뒀다면 **py list**로 지금 어떤 버전이 기본인지 볼 수 있어요.

### 예전 설치 파일로 깔 때

<figure class="shot">
  <a href="/images/articles/python-download-card-3.webp" class="shot__zoom"><img src="/images/articles/python-download-card-3.webp" width="800" height="496" alt="윈도우 파이썬 설치 관리자와 예전 설치 파일 비교. 설치 관리자는 지금 추천하는 방식으로 python과 py 명령을 바로 쓰고 버전 여러 개를 관리하며 3.16 이후에도 계속 나와요. 예전 설치 파일(전체 설치 프로그램)은 3.14부터 지원 종료가 예고돼 PATH 체크를 직접 해야 하고 3.15까지만 나오며 3.16부터는 나오지 않아요." loading="lazy" decoding="async"></a>
  <figcaption>예전 설치 파일로 깔 때는 PATH 체크를 꼭 확인하세요.</figcaption>
</figure>

다운로드 페이지에는 예전 방식인 **Windows installer(64-bit)** 파일도 아직 있어요. 이건 3.14부터 지원 종료가 예고돼서, <mark>3.16부터는 나오지 않아요.</mark>

이 파일로 설치한다면 첫 화면에 있는 PATH 추가 체크박스(**Add python.exe to PATH**, 버전에 따라 이름이 조금 다를 수 있어요)를 꼭 켜고 **Install Now**를 누르세요.

<div class="box box--tip"><span class="box__title">제가 헤맨 부분</span>저는 이 체크를 안 하고 설치했다가 실행이 안 돼서 고생했어요. 체크 하나로 끝날 일이니 설치 버튼 누르기 전에 꼭 한 번 보세요!</div>

## 파이썬 설치 방법 맥

맥은 설치 파일 하나로 끝나요.

1. python.org 다운로드 페이지에서 **macOS 설치 파일**(.pkg)을 받아요
2. 받은 파일을 더블클릭하면 맥 기본 설치 프로그램이 열려요
3. **계속**을 눌러 안내대로 진행하면 돼요

이 설치 파일은 애플 실리콘(M 칩)과 인텔 맥에서 모두 돌아가고, 보통 macOS 10.15 카탈리나 이후 버전에서 쓸 수 있어요. 맥에 원래 들어 있는 python3는 개발 도구용 옛 버전이라 지우거나 고치지 마세요.

## 파이썬 실행 방법과 버전 확인

설치가 잘 됐는지는 버전 숫자로 확인하는 게 제일 빨라요.

- **윈도우:** 터미널에 python --version 입력
- **맥:** 터미널에 python3 --version 입력

Python 3.15.2처럼 버전이 나오면 성공이에요! 그다음에는 python(맥은 python3)만 입력하면 코드를 바로 쳐 볼 수 있는 화면이 열려요.

## 파이썬 다운로드 안됨 실행 안될 때 해결

<figure class="shot">
  <a href="/images/articles/python-download-card-4.webp" class="shot__zoom"><img src="/images/articles/python-download-card-4.webp" width="800" height="570" alt="파이썬 실행 안될 때 확인할 것. 앱 실행 별칭에서 Python을 켜고, py 명령이 되는지 확인하고, PATH에 설치 경로를 넣고, 예전에 깐 파이썬을 정리해요." loading="lazy" decoding="async"></a>
  <figcaption>python을 쳤는데 스토어가 열리거나 명령을 못 찾을 때예요.</figcaption>
</figure>

설치는 했는데 python을 쳤더니 **마이크로소프트 스토어가 열리거나** "명령을 찾을 수 없다"는 말이 나온다면 아래 순서로 보세요.

1. 시작 메뉴에서 **앱 실행 별칭 관리**를 열고 Python 항목이 켜져 있는지 봐요. 켜져 있으면 껐다가 다시 켜 보세요
2. **py** 명령은 되는지 확인해요. py가 되면 설치 자체는 잘 된 거예요
3. 예전 설치 파일로 깔았다면 PATH 체크를 안 했을 가능성이 커요. 다시 설치하면서 체크하면 가장 빨라요
4. 예전에 깔아 둔 파이썬이 있으면 서로 꼬일 수 있어요. 안 쓰는 버전은 지우고 다시 확인하세요

## 파이썬 다운로드 아이패드에서 하는 법

python.org에 iOS용 파일이 있긴 하지만 앱 개발자용이라, 아이패드에 바로 설치하는 파일은 없어요. 그래서 PC처럼 파이썬을 깔 수는 없고, 앱스토어의 파이썬 실행 앱이나 웹에서 코드를 돌려 주는 서비스를 써야 해요.

본격적으로 배울 거라면 PC나 맥에 설치하는 쪽이 훨씬 편해요. 오늘 python.org에서 바로 받아서 버전 확인까지 해 보세요!
